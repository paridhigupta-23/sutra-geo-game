# SUTRA-GEO Cultural Games — SIH26208

The project keeps the original SUTRA-GEO pages and functionality while adding a game-first Cultural Games hub.

## New game hub
- Rapid Fire
- Memory Match
- Word Scramble
- Tap Rush reaction game
- Guess the Place
- Match It
- Coin Spinner
- Geo Hunt
- Challenge Arena
- Existing quest/XP/collection flow remains accessible

## Navigation
A `🎮 Cultural Games` link is added to the navbar of every HTML page that already has the main navigation.

## Run
Open `explore.html` or any page and select Cultural Games. `game.html` is the main arcade page.
